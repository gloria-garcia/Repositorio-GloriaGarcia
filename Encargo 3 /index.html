PUNTO DE PARTIDA

Dos maneras de relacionarse con el patrimonio.

Para este análisis se seleccionaron dos experiencias digitales vinculadas al patrimonio cultural:

Servicio Nacional del Patrimonio Cultural como sitio web institucional y IDE Patrimonio como plataforma web.

Ambos trabajan sobre un mismo ámbito, pero organizan la información de maneras diferentes porque las acciones que permiten realizar también son diferentes.

El sitio web prioriza la información y navegación, mientras la plataforma incorpora herramientas para explorar información territorial.

01

¿Qué tipo de sitio es?

El Servicio Nacional del Patrimonio Cultural funciona como un sitio web institucional. Su función principal es organizar y comunicar información relacionada con el patrimonio y los servicios que ofrece la institución.

Su estructura reúne distintos tipos de contenido: noticias, actividades, publicaciones, servicios, instituciones y otros recursos relacionados con el patrimonio cultural.

¿Cómo se organiza la navegación?

La navegación permite acceder a diferentes áreas del contenido institucional. La página necesita separar información de distinta naturaleza sin perder una estructura común.

¿Qué se mueve y qué permanece?

El recorrido principal del sitio se construye mediante un desplazamiento vertical. Al hacer scroll, el usuario atraviesa diferentes bloques de información.

El movimiento cumple principalmente una función de lectura y navegación. El usuario recorre noticias, servicios y contenidos sin necesitar cambiar constantemente de página.

A diferencia de la IDE Patrimonio, aquí el desplazamiento no constituye el espacio de trabajo principal. Sirve principalmente para recorrer información.

¿Cómo se distribuyen las columnas?

La composición utiliza una organización modular y multicolumna. Los contenidos pueden ocupar diferentes anchos dependiendo de su importancia y función.

En una pantalla amplia existe mayor disponibilidad horizontal, por lo que distintos módulos pueden convivir en una misma fila.

Esta organización resulta apropiada para un portal institucional porque permite manejar grandes cantidades de información sin convertir toda la página en una única columna de texto.

¿Qué ocurre al reducir la pantalla?

Al disminuir el ancho disponible, la composición debe reorganizar sus elementos para mantener la legibilidad.

Los contenidos que pueden disponerse horizontalmente en escritorio comienzan a ocupar más espacio vertical en dispositivos pequeños.

La lógica responsive permite que la estructura cambie de acuerdo con el ancho disponible en vez de intentar mantener exactamente la misma composición del computador.

¿Por qué es una plataforma web?

¿Qué se mueve y qué permanece?

En esta plataforma el movimiento tiene una función diferente. No se limita al scroll de la página, ya que existe un visor territorial interactivo.

El usuario puede explorar el territorio y visualizar diferentes registros patrimoniales mediante las capas disponibles.

03

¿Cómo se organiza la información?

La información patrimonial está organizada mediante capas. Esto permite visualizar diferentes tipos de patrimonio sin mostrar toda la información al mismo tiempo.

Entre las categorías disponibles se encuentran Monumentos Históricos, Monumentos Arqueológicos, Museos, Bibliotecas, Archivos, Sitios de Patrimonio Mundial y otras categorías patrimoniales.

Esta organización permite construir diferentes lecturas del territorio dependiendo de las capas que la persona usuaria decide consultar.

04

¿Cómo se distribuyen las áreas?

La distribución responde a una lógica de interfaz de herramienta. El visor territorial ocupa el espacio principal porque allí se produce la visualización de los datos.

Las herramientas, controles y opciones de consulta funcionan como elementos secundarios que permiten modificar o complementar aquello que aparece en el espacio principal.

05

¿Qué ocurre al reducir la pantalla?

La adaptación responsive presenta un desafío mayor porque la plataforma no solamente debe conservar textos e imágenes: debe mantener disponible la interacción con el visor.

Al disminuir el espacio horizontal, las herramientas deben reorganizarse para no ocupar el espacio necesario para visualizar el territorio.

Por esta razón, el responsive de una plataforma cartográfica debe proteger principalmente la interacción y no solamente la apariencia.

01 / COMPUTADOR

Existe mayor espacio para relacionar el visor con las herramientas de consulta.

02 / TELÉFONO

La interfaz debe priorizar el visor y mantener accesibles sus herramientas principales.

MI
OPINIÓN

Considero que la estructura de IDE Patrimonio es coherente con su objetivo porque el mapa no funciona solamente como una imagen, sino como el espacio principal de interacción.

La utilización de capas permite organizar una gran cantidad de información sin saturar permanentemente la visualización.

Como mejora, reforzaría la jerarquía de las herramientas en teléfonos para que sea más evidente dónde buscar, activar una capa y volver a la visualización principal.

CONCLUSIÓN

La forma responde a la acción.

El análisis muestra que ambos sitios trabajan con el patrimonio cultural, pero necesitan estructuras diferentes porque las acciones que proponen también son diferentes.

El Servicio Nacional del Patrimonio Cultural funciona principalmente como un espacio de información y navegación. Por eso su estructura puede entenderse desde una lógica editorial y multicolumna, capaz de organizar grandes cantidades de contenido.

IDE Patrimonio, en cambio, funciona como una herramienta de exploración. La información no solamente se lee: puede consultarse, visualizarse territorialmente y organizarse mediante capas.

El sitio organiza información para ser recorrida. La plataforma organiza información para ser explorada.
